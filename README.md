# 🤖 SmolAgents & WebSearchTool

An AI Agent project built using **SmolAgents**, **Hugging Face**, and **WebSearchTool**. This project demonstrates how AI agents can use language models and external tools to perform tasks and retrieve information from the web.

---

## 📌 Project Overview

This repository contains two Jupyter Notebook implementations:

- **SmolAgents** – Creating and running an AI agent using `CodeAgent` and a Hugging Face inference model.
- **WebSearchTool** – Using `WebSearchTool` to enable an AI agent to search the web and retrieve relevant information.

---

## 🛠️ Technologies Used

- Python
- SmolAgents
- Hugging Face
- WebSearchTool
- Gemini API
- Jupyter Notebook
